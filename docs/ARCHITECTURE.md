# Architecture
Swift 6 / SwiftUI; iOS 17+. Adaptive five-tab iPhone navigation and iPad sidebar. Arabic default with in-app English selection. Native catalog/search/favorites/recents stored locally. Website features retain their server behavior in persistent WKWebView sessions; external sites use system browser. No fabricated APIs or scraped student data.
No production site mutations. No credentials in source. Native UI and Web integration have distinct ownership.
